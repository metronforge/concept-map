# CSS contract

Import `@metronforge/concept-map/css`. Set these properties on the figure or a host rule. Defaults are neutral; the book supplies its existing theme.

- `--cmap-accent` — host colour.
- `--cmap-accent-low` — host colour.
- `--cmap-app` — host colour.
- `--cmap-bg` — host colour.
- `--cmap-border` — host colour.
- `--cmap-browser` — host colour.
- `--cmap-client` — host colour.
- `--cmap-fail` — host colour.
- `--cmap-fg` — host colour.
- `--cmap-font-mono` — font family.
- `--cmap-font-sans` — font family.
- `--cmap-muted` — host colour.
- `--cmap-muted-fg` — host colour.
- `--cmap-node` — host colour.
- `--cmap-page` — host colour.
- `--cmap-protocol` — host colour.
- `--cmap-runner` — host colour.
- `--cmap-server` — host colour.
- `--cmap-test` — host colour.
- `--cmap-text-accent` — host colour.

Legacy inline layer aliases, `--c`, and `--map-label-min` are internal format-2 debt (D1). DOM classes and functional layout remain unchanged. Book `.pwc` padding and concept section margins stay in the host.
